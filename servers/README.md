# MCP-серверы

Каждый сервер — самостоятельный npm workspace `servers/<имя>` со своим composition root, который host запускает
отдельным процессом по stdio. Сейчас один сервер — [git](git/README.md): читающие инструменты git проекта (ADR 0002).

## Правила

- Сервер не импортирует `apps/` и соседние серверы; host не импортирует серверы. Общий код дублируется.
- Состав workspace: `README.md`, `AGENTS.md`, `CLAUDE.md`, `package.json`, `tsconfig.build.json`, `src/index.ts`,
  `src/app/main.ts`, тесты. stdout — только протокол MCP, логи — в stderr.
- SDK — `@modelcontextprotocol/server` с явной версией; инструменты регистрируются с `inputSchema` и аннотациями
  `readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`.
- Инструменты по умолчанию только читают и не выходят за корень проекта, переданный аргументом запуска. Запись, сеть
  и произвольные команды — только по отдельному ADR с подтверждением человека (корневой AGENTS.md, «Песочница»).
- Ошибка инструмента возвращается результатом с `isError`, а не исключением; текст называет реальную причину.
- Протокольный тест — через `InMemoryTransport` и настоящий `Client`; `tooling/build.ts` запускает собранный сервер
  из другого каталога и сверяет список его инструментов.
