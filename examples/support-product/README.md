# Acme Notes

Acme Notes — вымышленный облачный сервис заметок: заметки синхронизируются между устройствами, команды на тарифе
Business входят через корпоративный SSO. Продукт нужен как демо для ассистента поддержки devflow-lab
(`support <тикет> <вопрос>`, [ADR 0004](../../docs/adr/0004-support-assistant.md)); все данные вымышлены.

## Документация

- [Вход и авторизация](docs/auth.md) — пароль, SSO, блокировка после неудачных попыток, сброс пароля, 2FA.
- [Тарифы и оплата](docs/plans.md) — Free, Pro, Business, неоплата и приостановка аккаунта, смена тарифа.
- [Частые вопросы](docs/faq.md) — короткие ответы на типичные обращения.

## Данные поддержки

`support/tickets.json` — клиенты и тикеты для MCP-сервера поддержки (`servers/support`). Конфигурация запуска —
`support.config.yaml`.
