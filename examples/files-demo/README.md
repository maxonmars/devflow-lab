# Загрузчик файлов (демо для `files`)

Фикстура для [демо ассистента файлов](../../docs/demos/files-assistant.md): лимиты загрузчика описаны в таблице ниже
и заданы в `src/limits.ts`. Код не запускается — он нужен, чтобы менять его и просить ассистента обновить документацию.

## Лимиты

| Параметр | Значение | Описание |
|---|---|---|
| `MAX_FILE_MB` | 10 | Максимальный размер одного файла, МБ |
| `MAX_FILES` | 20 | Максимум файлов за одну загрузку |
| `UPLOAD_TIMEOUT_S` | 30 | Таймаут загрузки, секунды |
