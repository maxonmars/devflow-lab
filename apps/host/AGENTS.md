# Правила host

Общие правила находятся в [корневом AGENTS.md](../../AGENTS.md).

- main.ts читает окружение и argv, compose.ts связывает зависимости.
- Agent хранит только модель и системную инструкцию; между вызовами respond() состояния нет, историю передаёт вызывающий: `respond(input, { history })`.
- Публичный порт ядра — ModelPort.complete(request: ModelRequest): Promise<ModelCompletion>; не добавляй методы ради будущих фич.
- DeepSeek-специфичные параметры и SDK-типы не выходят из adapters/llm.
- Порт эмбеддингов — EmbeddingPort фичи rag; ModelPort для эмбеддингов не расширяется.
- CLI отображает AgentError и RagError, не печатает необработанные ошибки SDK, тела ответов Ollama и значения настроек.
- Команда описывается в app/commands.ts один раз; CLI и REPL используют один dispatcher.
- Настройки описываются в app/settings.ts; тексты справки и описания находятся рядом в .md.
- Режим RAG — локальная переменная сессии в compose.ts (`/rag on`, `/rag off`); `ask` и строка REPL следуют ему, `rag ask` всегда с RAG и без истории. История и память задачи — только в режиме RAG в REPL (ADR 0006): локальная переменная `dialog` в compose.ts, без файлов сессий. `rag serve` (ADR 0010) держит диалоги по `session_id` в памяти процесса (`app/ragSessions.ts`).
- Поиск, rewrite, отбор по порогу, склейка фрагментов, калибровка и сравнение режимов — в features/rag; app хранит режим сессии, передаёт настройки и связывает зависимости.
- Индекс пишется только целиком: собирается в памяти, затем временный файл рядом и rename.
- Тесты лежат рядом с модулем в tests; тесты app используют harness.ts, а не файлы tests фичи.
- npm run check выполняется из корня монорепозитория.
