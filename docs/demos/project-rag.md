# Демо: RAG по документации самого репозитория

Проверяет каркас недели (ADR 0001): корпус из `rag.include` внутри `project.root`, индекс v2, ответ с цитатами и
«не знаю». Нужны запущенная Ollama с `bge-m3` и `LAB_LLM_API_KEY` (DeepSeek).

## Шаги

```sh
npm run dev -- config show
npm run dev -- rag index
npm run dev -- rag ask "Какие проверки входят в npm run check?"
npm run dev -- rag ask "Какой рецепт борща?"
npm run dev -- --project-root ../rag-lab --rag-output-dir .local/rag-other rag index
```

## Ожидаемый результат

- `config show` показывает `project.root` = `.`, `rag.include` со списком шаблонов и `mcp.timeoutMs` = 10000, источник —
  `default`.
- `rag index` печатает в stderr «Разбиение» и «Эмбеддинги», в stdout — число документов, модель и число чанков; индекс —
  `.local/rag/index.json`.
- Вопрос о `npm run check` получает ответ с источниками из README.md, ARCHITECTURE.md или ADR 0001 и цитатами с
  отметкой «найдена».
- Вопрос не о проекте получает «не знаю» по порогу 0.55 без вызова модели и строку «Фрагменты: контекст пуст».
- С `--project-root ../rag-lab` индексируются документы соседнего репозитория; свой индекс не перезаписывается.
