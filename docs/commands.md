# Команды

Генерируется из реестра: `npm run docs:generate`.

CLI: `npm run dev -- <команда>`. Без команды запускается REPL; обычная строка вызывает ask.
CLI-флаги задаются при запуске. В REPL настройки не изменяются.
CLI использует quoting оболочки; в REPL остаток /ask передаётся как текст без обработки кавычек.

| CLI | REPL | Описание |
|---|---|---|
| ask <текст...> | /ask | Отправить реплику агенту без поиска по документам и без истории. Агент может вызывать инструменты подключённых MCP-серверов; до появления первого сервера ответ идёт без инструментов. Нужен LAB_LLM_API_KEY при llm.provider: deepseek. |
| info <вопрос...> | /info | Ответ ассистента проекта: фрагменты документации project.root из index.json и git-инструменты проекта (ветка, статус, diff, список файлов), которые модель вызывает сама. Ответ содержит источники с проверенными цитатами и раздел «Данные проекта» с фактами инструментов. Нужны индекс, запущенная Ollama и LAB_LLM_API_KEY при llm.provider: deepseek. |
| help | /help | Показать команды и флаги настроек. |
| config show | /config show | Показать действующие настройки и их источники без значений секретов. |
| rag index | /rag index | Собрать корпус из Markdown-файлов rag.include внутри project.root, разбить его на чанки по заголовкам и блокам Markdown, получить эмбеддинги через Ollama и сохранить индекс в index.json. Нужны запущенная Ollama и скачанная модель. |
| rag ask <текст...> | /rag ask | Найти в index.json фрагменты по вопросу в режиме rag.retrievalMode (по умолчанию rewrite-filter) и ответить по ним, без истории: каждый вопрос одиночный. Ответ содержит источники и цитаты; если после отбора фрагментов нет — «не знаю» с просьбой уточнить вопрос без вызова модели. Нужны индекс, запущенная Ollama с моделью индекса и LAB_LLM_API_KEY при llm.provider: deepseek. |
| exit | /exit | Завершить ввод реплик. |

Алиасы help: --help, -h.
Чтобы передать текст, начинающийся с --, используйте `ask -- <текст>`.
