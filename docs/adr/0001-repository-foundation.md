# 0001 — Основа репозитория

Статус: принято по подтверждению создания devflow-lab.
Дата: 2026-10-13.

## Контекст

Седьмая неделя курса — AI в рабочем процессе разработчика: ассистент, знающий проект; ревью PR в GitHub Actions;
пайплайны с триггерами; субагенты. Заданиям нужны и «память» (RAG по документации проекта), и «руки» (MCP-инструменты
проекта). Память реализована в rag-lab, руки — в mcp-lab; каждый репозиторий написан про свою тему недели.
Прежние блоки курса начинались в новом репозитории с копией отлаженного каркаса (ADR 0001 rag-lab).

## Варианты

- Продолжить rag-lab: RAG готов, но цель, AGENTS.md и ADR написаны про RAG, а MCP-клиента нет.
- Продолжить mcp-lab: MCP готов, но ядро старше (нет `history` в Agent, нет локальной модели), RAG нет.
- Общий пакет для трёх репозиториев: связывает учебные репозитории версиями и не нужен ни одному заданию.
- Новый репозиторий с копией нужного из обоих: чистая цель недели, работа не повторяется.

## Решение

- Новый репозиторий devflow-lab, npm workspaces `apps/*` и `servers/*`; `servers/` пуст до первого сервера.
- Из rag-lab перенесены tooling, конфигурации Biome, TypeScript и Vitest, pre-commit и CI, ядро (Agent с циклом
  инструментов, ModelPort, ToolSource, AgentError), адаптеры DeepSeek и локального сервера, CLI, реестры настроек и команд.
- Фича rag перенесена с сокращениями:
  - корпус — Markdown-файлы по шаблонам `rag.include` внутри `project.root` (по умолчанию сам репозиторий) вместо
    каталога `rag.inputDir`; шаблоны вне корня отклоняются, символические ссылки пропускаются;
  - одна стратегия чанкинга — по структуре Markdown, индекс `formatVersion: 2` без раздела стратегий;
  - остались `rag index` и `rag ask` с четырьмя режимами поиска, порогом, цитатами и «не знаю».
- Из mcp-lab перенесены `withStdioToolSource` с ошибками и тестами, `combineToolSources`, `observedToolSource` и
  вложенное открытие сессий. `ask` открывает сессии серверов из `RunOptions.mcpServers` на каждую реплику; лимит —
  `ASK_MAX_TOOL_CALLS = 6`.
- Не перенесены: RAG-чат с памятью задачи, `rag compare`, `rag calibrate`, `rag eval`, `rag citations`, `rag dialog`,
  `rag serve` и `adapters/http`, шлюз `servers/llm-gateway`, подготовка корпуса FEOD и эксперименты, ADR 0002–0010
  rag-lab; из mcp-lab — discovery Filesystem, серверы и фичи погоды, планировщика и зависимостей, `serverEntrypoints.ts`
  (переносится вместе с первым сервером).
- Префикс env `LAB_` сохранён для преемственности с прошлыми репозиториями.
- В AGENTS.md добавлено правило песочницы: инструменты по умолчанию только читают; запись, сеть и разрушающие
  операции — через ADR и подтверждение человека.

## Последствия

- Порог 0.55 откалиброван в rag-lab на корпусе FEOD; для документации проекта он не калибровался.
- RAG требует локальной Ollama с `bge-m3`; в GitHub Actions её нет — вопрос дня 2, варианты в docs/course.md.
- Индекс не сверяет `project.root` и `rag.include`: после их смены индекс пересобирается вручную.
- `help` уже занят справкой по командам, а день 1 требует `/help <вопрос>`; в ADR 0002 ассистент вынесен в отдельную
  команду `info`, `help` остался справкой.
- Изменения правил rag-lab и mcp-lab сюда автоматически не переносятся.
